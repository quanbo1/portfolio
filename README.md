# 洞洞板作品集 · PEGBOARD PORTFOLIO

参考实物桌面「洞洞板」风格制作的个人作品集单页，中文 + 等宽英文混排。

## 设计语言

- 米色洞洞板背景（CSS 圆孔阵列 + 暗角光影）
- 左侧牛皮纸信息卡：板面目录、实物交互说明、大字标语、二维码
- 五个拟物挂件：黄色钥匙牌（简介）、亚克力证件框（精选作品）、织物工牌（履历）、黑色椭圆技能牌、航空信封联系卡、OPEN TO WORK 条形码吊牌、便利贴
- 金属挂环 / 证件夹细节，悬停摆动效果
- 点击挂件弹出深色弹窗：作品网格（分类筛选）、技能拱门形卡片、个人履历、联系卡

## 使用

直接用浏览器打开 `index.html`，无需构建。

## 自定义

- 作品数据在 `index.html` 底部的 `WORKS` 数组中修改
- 弹窗中的简历、联系方式直接改对应 HTML 区块
- 封面图为 Unsplash 占位图，替换为真实作品图即可
