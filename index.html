01
Where it started

一切从「卖不出去的闲置」开始

嘎……先想想

每个宿舍角落都堆着「懒得卖」的东西：教材、台灯、小家电。不是不想卖，而是 定价没参照、消息被刷走、和陌生人沟通太费劲。我们把这些原话写成 POV，再转成 HMW。

1

定价的焦虑

「这个到底值多少钱？」定价没有参照物，只能凭感觉，最后要么卖不掉，要么贱卖。

来自宿舍夜谈的真实抱怨，也是问卷里被提到最多的痛点。

2

消失的信息

「刚发的消息被刷走了。」群里一条转让消息几分钟就沉底，想找某样东西只能翻聊天记录。

熟人渠道有信任，但信息无法沉淀、无法检索。

3

沟通的成本

「约了三次都没遇上。」和陌生人约面交、砍价、售后，每一步都在消耗耐心。

大平台解决「买得到」，却没解决「今天下午顺路拿到」。

待验证的设计机会 Opportunity

  1. 现象发现现象

    大学生校内闲置交易渠道分散，拼单、代取等需求无法统一解决。

  2. 问题识别问题

    现有渠道普遍存在帖子易沉没、同校比价困难、功能割裂、交易风险等痛点。

  3. 机会提出机会

    搭建本校专属平台，闲置比价为核心，整合拼单、代取快递等校内服务。

  4. 验证假设

    通过问卷、用户访谈验证需求真实性。

调研对象：本校在校本科生、研究生。问卷计划回收 120 份以上，覆盖不同年级、不同院系；访谈 8~10 人，筛选经常在二手群 / 闲鱼买卖闲置、愿意尝试校内跑腿的同学。

1. 第 1 天：编写问卷题目、整理访谈提纲
2. 第 2–3 天：投放问卷，同步邀约访谈对象，开展访谈、录音记录（征得同意）
3. 第 4 天：整理问卷数据、转录访谈要点，汇总问题和需求
分工：主负责人——统筹进度、邀约访谈对象、整理最终调研报告；记录员——访谈文字记录、整理问卷回收数据与原始材料。

调研核心问题方向 KEY QUESTIONS
问卷重点：是否买 / 卖过校园闲置、平时在哪交易、最讨厌什么问题；是否愿意寝室点点配送；能接受的跑腿费用；会不会参考历史成交定价；担心哪些风险（物品损坏、跑腿人员安全、交易纠纷）。
访谈重点：交易踩过什么坑；如果有跑腿，下单和收货最在意什么；定价一般怎么估；对 App 还有什么额外期待。

四种最常见的坑 Common traps

坑常见写法 ✗改进写法 ✓
一题问两件事「发布 & 沟通 & 你会觉得麻烦吗？」拆开问：发布麻烦吗？沟通麻烦吗？
选项不周全「使用频率：1–3 / 3–5 / 5 次以上」（漏了 0 次）加「0 次」，覆盖不使用者
带倾向的选项「它是非常好用还是太难用？」（暗示难用）改中性：使用中经常遇到哪些问题？
问未来不问过去「以后会经常用这个 App 吗？」问真实行为：你最近一次没买成的东西是什么？

问卷提交卡 · 五个测量板块 Question card · 试填 30 人后修订投放

  1. 一、基础背景信息（用户画像）——年级；在校闲置出售 / 收物频率（从不 / 一学期 1–2 次 / 每月 1 次 / 每月多次）；是否参与过校内拼单、是否使用过代取快递服务。
  2. 二、现有渠道使用情况（闲鱼 / 转转 / 小红书 / 校园二手群）——常用渠道（多选）；在该渠道遇到痛点的困扰程度（李克特 5 分）：帖子很快被刷下去需反复重发 · 难查本校同类闲置参考价、定价困难 · 校外无关人员过多 · 平台手续费 / 快递成本高 · 交易缺少保障担心被骗 · 拼单代取要换到别的软件 / 群聊操作很麻烦。
  3. 三、核心功能需求测量（5 分打分）——仅限本校学生登录的闲置交易板块；发布闲置时自动查看本校同类商品历史成交价作为定价参考（核心卖点）；校内拼单板块（零食、周边、二次元 / 追星团购）；校内代取快递互助板块；校内定点自提交易方式。
  4. 四、产品接受意愿测量——如果有本校专属一体化平台，是否愿意尝试使用；相比闲鱼 / 二手群优先选择本校平台的原因（多选）；可接受的平台形式（微信小程序 / App / 网页端）。
  5. 五、风险与顾虑测量——使用本校平台最担心的问题（信息泄露、没人用、交易纠纷、功能不好用等）。

Test & Iterate

真实上手之后：2.0 → 3.0

2.0 上线给同学真实使用后，我们按反馈逐条修：左边是旧版本，右边是 3.0 新版本。 每一条改动都来自一个具体的吐槽。

01 编辑资料上线——2.0 里还是「功能开发中」，3.0 可以直接改头像、昵称、性别与个性签名。

02 把缺失的选项补齐——消息页空状态没退路，3.0 补上了完整底部导航。

03 我的页做减法——偏好档案、相似匹配等复杂设置收起，页面更清爽、退出登录更明确。

04 广场更好逛——新增「我的点赞 / 我的收藏」、表情评论、图片点击放大。

05 分类移到首页——新增推荐 / 最新发布 / 热门商品与筛选，热门闲置不再一屏刷到底。

06 图片放大观看——详情页图片支持全屏查看，成色细节看得清再下单。

07 发布更完整——新增「出闲置 / 收闲置」类型与库存设置（卖出自动减、0 件自动下架）。

08 库存可观察 + 可再编辑——详情展示库存件数；卖家可以随时重新编辑已发布的商品。
